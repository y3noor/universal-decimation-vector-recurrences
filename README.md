# Universal Decimation and Commutativity in Vector Linear Recurrences

This repository contains code and saved records for the paper's finite searches, cubic example, and size inequalities.

```sh
sh reproduce/replay.sh quick
```

Run from the repository root with a POSIX shell, Python 3.10 or later,
and GCC or Clang with C++17 support available as `c++`.

See the [replay guide](reproduce/README.md) for the scope of each check,
the saved evidence, and the optional checks.
